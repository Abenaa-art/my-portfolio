PUT YOUR PROJECT IMAGES IN THIS FOLDER
--------------------------------------
Tip: make one sub-folder per project, e.g.
   assets/projects/coffee-brand/01.jpg
   assets/projects/coffee-brand/02.jpg

Then write the same paths in js/config.js:
   images: ["assets/projects/coffee-brand/01.jpg", "assets/projects/coffee-brand/02.jpg"]

Tips:
- Export as JPG (photos, mockups) or WebP/PNG (flat graphics, logos with transparency).
- About 1600 px on the long side is plenty. Keep each file under ~400 KB (use https://squoosh.app).
- File names: lowercase, no spaces, e.g. 01.jpg
- featured.jpg = the big image under the intro (wide, 1920 px).
